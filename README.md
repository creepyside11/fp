# FunPay Telegram Bot

Telegram-бот на aiogram 3, который подключает аккаунт FunPay через обязательный прокси и GOLDEN_KEY. После подключения пользователь может посмотреть баланс, профиль и все опубликованные объявления.

## Возможности

- последовательное подключение: прокси → проверка прокси → GOLDEN_KEY;
- поддержка HTTP(S), SOCKS4 и SOCKS5 прокси;
- проверка GOLDEN_KEY через `FunPayAPI.Account.get()`;
- баланс в RUB, USD и EUR (общий и доступный к выводу);
- профиль, статус, блокировка, активные продажи/покупки;
- список объявлений с пагинацией;
- PostgreSQL через `DATABASE_URL`;
- зашифрованное хранение прокси и GOLDEN_KEY;
- попытка сразу удалить сообщения пользователя с прокси и ключом.

## Переменные окружения

Обязательны только:

```env
BOT_TOKEN=123456:telegram-bot-token
DATABASE_URL=postgresql://user:password@host:5432/database
```

Ключ шифрования для сохранённых данных детерминированно создаётся из `BOT_TOKEN`, поэтому отдельная переменная не нужна. Если `BOT_TOKEN` заменить, старые записи перестанут расшифровываться — пользователям потребуется выполнить `/reset` и подключиться заново.

## Запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

При первом запуске таблица `funpay_bot_users` создаётся автоматически. Бот работает через long polling, поэтому хостинг должен поддерживать постоянно запущенный worker-процесс.

## Команды

- `/start` — начать настройку или открыть меню;
- `/reset` — удалить сохранённое подключение и пройти настройку заново.

## Безопасность

GOLDEN_KEY даёт доступ к авторизованной сессии FunPay. Не публикуйте его и не пересылайте третьим лицам. Бот шифрует GOLDEN_KEY и прокси перед записью в PostgreSQL, не выводит их в логи и пытается удалить исходные сообщения из Telegram.

Интеграция использует неофициальную библиотеку [LIMBODS/FunPayAPI](https://github.com/LIMBODS/FunPayAPI). Изменения на стороне FunPay могут временно нарушить получение данных.
