# FunPay Telegram Bot

Telegram-бот на aiogram 3, который подключает аккаунт FunPay через обязательный прокси и GOLDEN_KEY. После подключения пользователь может посмотреть баланс, профиль и объявления, получать уведомления и автоматически поднимать лоты.

## Возможности

- последовательное подключение: прокси → проверка прокси → GOLDEN_KEY;
- поддержка HTTP(S), SOCKS4 и SOCKS5 прокси;
- проверка GOLDEN_KEY через `FunPayAPI.Account.get()`;
- баланс в RUB, USD и EUR (общий и доступный к выводу), получаемый через актуальный публичный лот вместо ненадёжного ID из библиотеки;
- профиль, статус, блокировка, активные продажи/покупки;
- список объявлений с пагинацией;
- уведомления о новых заказах;
- уведомления о новых сообщениях с ником собеседника;
- резервная проверка последнего сообщения для уже существующих чатов;
- сохранение ID обработанных сообщений в PostgreSQL для защиты от пропусков и дублей;
- ответ в чат FunPay прямо из уведомления Telegram;
- отдельные переключатели уведомлений о заказах и сообщениях;
- настраиваемое автоприветствие после первого сообщения нового клиента;
- редактирование названий, описаний, цены, количества и активности существующих объявлений;
- ручное и автоматическое поднятие стандартных лотов;
- отдельный переключатель уведомлений об успешном автоподнятии;
- планирование следующего поднятия по таймеру ожидания, который возвращает FunPay;
- PostgreSQL через `DATABASE_URL`;
- зашифрованное хранение прокси и GOLDEN_KEY;
- попытка сразу удалить сообщения пользователя с прокси и ключом.

## Переменные окружения

Обязательны только:

```env
BOT_TOKEN=123456:telegram-bot-token
DATABASE_URL=postgresql://user:password@host:5432/database
```

Ключ шифрования для сохранённых данных детерминированно создаётся из `BOT_TOKEN`, поэтому отдельная переменная не нужна. Если `BOT_TOKEN` заменить, старые записи перестанут расшифровываться — пользователям потребуется выполнить `/reset` и подключиться заново.

## Запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

При первом запуске таблицы и новые столбцы настроек создаются автоматически. Бот работает через long polling и в фоне проверяет события FunPay, поэтому хостинг должен поддерживать один постоянно запущенный worker-процесс. Несколько одновременных копий worker могут дублировать уведомления.

## Команды

- `/start` — начать настройку или открыть меню;
- `/reset` — удалить сохранённое подключение и пройти настройку заново.

## Безопасность

GOLDEN_KEY даёт доступ к авторизованной сессии FunPay. Не публикуйте его и не пересылайте третьим лицам. Бот шифрует GOLDEN_KEY и прокси перед записью в PostgreSQL, не выводит их в логи и пытается удалить исходные сообщения из Telegram.

Интеграция использует неофициальную библиотеку [LIMBODS/FunPayAPI](https://github.com/LIMBODS/FunPayAPI). Изменения на стороне FunPay могут временно нарушить получение данных.

В FunPayAPI 1.1.0 нет документированного метода создания нового объявления. Бот не отправляет недокументированные запросы создания, но поддерживает полное редактирование уже существующих лотов через `get_lot_fields()` и `save_lot()`.
